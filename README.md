# Digital Clock Using Python

## Project Overview
This project is a Digital Clock developed using Python and Tkinter. The clock displays the current system time and updates automatically every second in a graphical user interface.

## Features
- Real-time clock display
- Automatic time updates every second
- User-friendly graphical interface
- Lightweight and easy to run

## Technologies Used
- Python
- Tkinter

## Project Structure
Digital_Clock/
│
├── digital_clock.py
└── README.md

## How to Run
1. Install Python on your system.
2. Save the code as `digital_clock.py`.
3. Open a terminal or command prompt.
4. Run:

python digital_clock.py

## Expected Output
A digital clock window will open and display the current time, updating every second.

## Learning Outcomes
- Python GUI programming
- Working with Tkinter
- Using functions and event scheduling
- Building real-time applications

## Conclusion
This project demonstrates how Python can be used to create simple graphical applications. The Digital Clock provides a practical example of real-time updates using the Tkinter library.
